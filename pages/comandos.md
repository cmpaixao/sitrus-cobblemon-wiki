# 🧭 **Comandos & Atalhos de Teclado**

{% hint style="info" %}
Confira os atalhos de teclado do Cobblemon e a lista oficial de comandos do Sitrus Cobblemon.
{% endhint %}

## 🎮 Teclas e Controles Padrão

| Tecla | Função | Descrição |
| --- | --- | --- |
| `R` | **Lançar Pokémon** | Envia ou recolhe o Pokémon atualmente selecionado na sua equipe lateral. |
| `↑ / ↓` ou `Scroll` | **Mudar de Pokémon** | Altera o Pokémon selecionado na barra lateral da sua equipe. |
| `B` | **Sumário do Time** | Abre a tela detalhada de status, golpes, EVs e IVs da sua equipe. |
| `Botão Direito` | **Interagir / Montar** | Interage com o Pokémon, alimenta bagas ou monta em espécies compatíveis. |

* * *

## ✨ Lista de Comandos

| Comando | Função |
| --- | --- |
| `/Menu` | Abre o menu principal do servidor. |
| `/Warps` | Abre a lista de warps para se teleportar. |
| `/Kits` | Abre os kits disponíveis para resgatar. |
| `/tpa` | Envia um pedido de teleporte até outro jogador. |
| `/tpacancel` | Cancela o pedido de teleporte enviado. |
| `/tpaccept` | Aceita um pedido de teleporte recebido. |
| `/tpahere` | Pede para outro jogador se teleportar até você. |
| `/flan menu` | Abre o menu do Flan para proteger e gerenciar o seu terreno. |
| `/raidglobal` | Abre o menu da [Raid Global](raids.md). |
| `/gts` | Abre o Global Trade Station para negociar Pokémon com outros jogadores. |
| `/sts` | Abre o Server Trade Station. |
